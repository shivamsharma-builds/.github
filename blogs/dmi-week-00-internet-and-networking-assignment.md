# Internet and Networking

This is the Week 00 write-up for my DevOps Micro Internship.

## What happens when you type a URL?

The browser resolves the domain through DNS, establishes the required network connection, negotiates security for HTTPS, sends an HTTP request, receives the response, and renders the returned resources.

## Key concepts

- DNS translates domain names into IP addresses.
- IP provides addressing and routing.
- TCP provides reliable transport; UDP provides lightweight datagrams.
- HTTPS protects HTTP traffic using TLS.
- HTTP defines communication between clients and servers.
- Packet switching allows data to travel across interconnected networks.

## Application architecture

A common three-tier application separates the presentation, application, and data layers. This separation supports independent scaling and clearer security boundaries.

## DevOps takeaway

Networking knowledge is foundational for troubleshooting deployments, DNS failures, load balancers, APIs, containers, cloud infrastructure, and CI/CD systems.
