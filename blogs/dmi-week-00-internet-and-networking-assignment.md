## What happens when you type a URL?

The browser first resolves the domain name through DNS. It then establishes the required network connection, negotiates HTTPS security when applicable, sends an HTTP request, receives the server response, and renders the returned resources.

## Key concepts

- **DNS:** resolves domain names to IP addresses.
- **IP:** provides addressing and routing between networks.
- **TCP/UDP:** transport protocols with different reliability and overhead characteristics.
- **HTTP/HTTPS:** application-layer web protocols; HTTPS adds TLS protection.
- **Ports:** identify services on a host.
- **Routing:** determines how packets travel between networks.

## DevOps takeaway

Networking fundamentals are essential when troubleshooting DNS, APIs, load balancers, cloud networking, containers, Kubernetes services, and CI/CD deployments.
